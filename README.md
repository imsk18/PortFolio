# 🌐 Personal Portfolio

A modern and interactive personal portfolio website built to showcase my **skills, projects, experience, and development journey**. The portfolio focuses on a clean UI, smooth animations, and an engaging user experience.

## ✨ Features

* 🏠 Modern and responsive design
* 👨‍💻 About Me section
* 🛠️ Skills & Technologies
* 🚀 Projects showcase
* 📩 Contact form
* ✨ Smooth animations and transitions
* 🎨 Interactive 3D elements
* 📱 Responsive across devices

## 🛠️ Technologies Used

* **Frontend:** React.js
* **Styling:** CSS
* **Animations:** GSAP
* **3D:** Three.js
* **Contact Form:** EmailJS
* **Language:** JavaScript
